# Reaction Time + Memory Challenge

3D reaction time + memory game built with Ursina. Press space when prompted + press the correct number when prompted.

## Requirements

- Python 3.7 or higher
- Ursina
- Pygame

## How to Run

1. Install requirements:
```
pip install ursina pygame
```

2. Run the game:
```
python game.py
```

## Controls

- **Spacebar**: Jump when "JUMP NOW!" appears (you have 0.8 seconds)
- **Number keys (1-9)**: Answer memory questions
- **ESC**: Quit game
